このサイトについて

このドメインは、Well-Known URI として定められたリソース（例: iOS Universal Links / Associated Domains 用の apple-app-site-association）を GitHub Pages（Jekyll）で公開するためのものです。

クライアントが実際に取得するのはルートではなく、通常は /.well-known/ 配下の URL です。

MyToybox の App Clip 用ランディングは https://koshimizu-takehito.github.io/my-toybox-clip/（リポジトリ: my-toybox-clip）です。
